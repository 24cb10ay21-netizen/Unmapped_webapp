THE UNMAPPED — Standalone Web App
=================================

RUN:
1. Extract the ZIP.
2. Double-click index.html (or right-click > Open with Chrome/Edge).
3. No Node.js, Python, API keys, or internet connection required.

FEATURES:
- Skills Signal Engine: extracts demo skills from free-text experience.
- Transition Recommender: target-role selector, overlap score, gaps, learning pathway.
- Market Insights: wage, growth and automation chart views.
- Export profile JSON.
- Responsive desktop/mobile layout.

IMPORTANT:
This is a working frontend prototype using illustrative demo skill taxonomy and market values.
Replace demo values with the hackathon organizer's Indian occupational skills dataset and supplied market datasets.
It does not claim a calibrated 12-month transition probability; that requires outcome data and calibration testing.
